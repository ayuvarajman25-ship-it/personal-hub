# Personal Hub

A personal Android app for reading, learning and screen-time awareness.

- `app/` the real app (Expo, React Native, TypeScript). See [app/README.md](app/README.md) for how to run it.
- `index.html` the clickable design mockup. Open it in a browser.

Topic content (Wikipedia, Wikiquote, Open Library, news) is fetched from the internet and saved on the phone.
Notes and topics stay on the phone.
